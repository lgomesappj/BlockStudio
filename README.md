# BlockStudio

Transforms complex data into easily accessible, shareable reports using a web-based interface for finance professionals and data analysts.

BlockStudio is built to be simple and practical, focusing on doing one thing well.

**Why BlockStudio?**

- Transforms complex data into easily

- web-based interface for finance professionals

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockStudio.git`
2. `cd BlockStudio`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
